# templates — 文书模板

本目录**不随仓库分发**作者所在律所的真实模板（那属于所内材料）。你要用自己的。

## 目录约定

```
templates/
├─ 所函模板.docx              # 所函生成（sohan_ops）：一个 docx，正文里写占位符
└─ 委托材料/                  # 委托六件套（commission_ops）
   ├─ 1、委托代理合同（简易版）.docx
   ├─ 2、授权委托书-民事.docx
   ├─ 3、办案反馈表.docx
   ├─ 4、聘请律师提示.docx
   ├─ 5、送达地址确认书-XXX法院格式.docx
   └─ 6、账户确认表-XXX法院格式.docx
```

文件名要与上面一致（`commission_ops.DOCS` 按文件名找模板）。法院名可以改成你的常用法院。

## 语法：docxtpl（Jinja2）

模板里用双花括号变量，由 `docxtpl` 渲染：

```
委托人：{{ client }}
相对方：{{ opponent }}
案由：  {{ cause }}
```

**不是**自制的字符串替换——支持 Jinja2 的 `{% if %}` 等语法，但**不要用循环与复杂逻辑**，文书模板越简单越不容易出错。

## 委托六件套的常用变量

| 变量 | 含义 | 必填 |
|---|---|---|
| `client` | 委托人 | 是 |
| `opponent` | 相对方 | 是 |
| `cause` | 案由（自动去掉「纠纷」尾缀） | 是 |
| `stage` | 审级（一 / 二 / 再审 / 执行） | 是 |
| `fee` | 律师费 | 是 |
| `auth_type` | 授权方式（一般 / 特别） | 是 |
| `case_type` | 案件类型（民事 / 刑事 / 行政） | 是 |
| `payee` | 收款人（缺省 = 委托人） | 否 |
| `lawyer` | 承办律师 | 否（取配置 `lawyer.name`） |
| `court` | 法院 | 否（取配置 `lawyer.default_court`） |

日期与签名一律**留空**，生成后在 Word 里手填——这是故意的，避免把「今天的日期」写进需要当场签署的文书。

## 两条硬规矩

1. **必填为空就拒绝生成**（blocked），不产出半空白文书。
2. **选填为空保留 `{{占位}}`**，不渲染成空白——空白会伪装成「已填写但内容为空」，导致漏填出厂。

## 把自己的模板标记化

如果你手上是普通 Word 模板（没有 `{{}}`），可以用 `extras/mark_commission_templates.py` 做一次批量标记，或手工替换。
标记完先拿一份 `demo/` 数据试生成，确认没有 `{{` 残留（程序会扫描并报错）。
